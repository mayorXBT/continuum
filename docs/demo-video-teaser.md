A punchy social/opening cut. Reuses the main video's assets and palette (see
`demo-video-prompt.md` / `DESIGN.md`). Lead with the money shot — it's the most convincing
proof the Cleanverse integration is load-bearing.

## Structure (~18s)

**1 · Hook (0:00–0:05)** — dark, guilloché grid.
"Compliant crypto checks you once — at the door." → hard cut → "Then never looks again."

**2 · Money shot (0:05–0:12)** — paper. Two wallet cards, both stamped green `A-PASS ✓`.
Wallet A `sub-tier 60` settles; Wallet C `sub-tier 10` reverts red `NotVerified`.
Caption: "Both verified. One refused — by Cleanverse's rule, not ours."

**3 · Never confiscated (0:12–0:15)** — the payout card: **1.1 MON returned**, "principal +
yield · frozen, never confiscated."

**4 · Logo lock-up (0:15–0:18)** — the mark + "Compliance that travels with the token." ·
`continuum` · Live on Monad testnet.

And a revoked holder still gets everything back. Continuum: compliance that travels with the
token."
